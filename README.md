
# Caixa Eletrônico em Python

Projeto de um caixa eletrônico desenvolvido em Python durante meus estudos de lógica de programação.

## Funcionalidades

- Consulta de saldo.
- Depósito com validação de valores.
- Saque com validação de saldo disponível.
- Histórico de depósitos e saques.
- Relatório final com total depositado, total sacado e quantidade de operações.
- Organização visual das mensagens usando funções.

## Tecnologias utilizadas

- Python 3
- Git
- GitHub
- Visual Studio Code

## Como executar

1. Instale o Python 3.
2. Clone este repositório ou baixe os arquivos.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo `main.py`.

Pelo terminal, também é possível executar:

```bash
python main.py
```

## Objetivo

Praticar conceitos fundamentais de Python, como variáveis, condicionais, laços de repetição, listas, funções e formatação de textos.
